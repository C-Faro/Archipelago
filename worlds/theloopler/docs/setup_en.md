## Required Software ##

- [The Loopler on Steam](https://store.steampowered.com/app/4150860/The_Loopler/)

## Usage ##

1. Download 'theloopler.apworld' from the [latest GitHub release](https://github.com/C-Faro/Archipelago/releases/tag/v0.0.1-alpha1)
2. Place it in your Archipelago's /custom_worlds folder
3. Generate a YAML by using the Options Creator and generate a game
4. Launch your preferred Universal Tracker or Text Client and connect to your game and slot

## Where do I get a YAML? ##

 YAMLs can either be made in the Options Creator or edited using a text editor and the YAML in the latest GitHub Release.
